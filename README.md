# Gamebase

A web hub for playing digital ports of physical board games with friends: share a link, join a room, and play live, with every move animated.

**Status:** design phase, with no code yet.

- [docs/DESIGN.md](docs/DESIGN.md): the platform design (stack, architecture, look and feel, build plan).
- [docs/PORTING.md](docs/PORTING.md): how a board game gets ported, with Camel Up as the first one.
